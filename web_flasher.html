ESP32-C3 Universal PS4 & PS5 RapidFire Mod v0.9.9

Web Flasher (ESP32-C3)

This page flashes the Universal RapidFire Mod v0.9.9 firmware to your ESP32-C3 installed inside:

  • PS4 DualShock: JDM-001 / 011 / 020 / 030 / 040 / 050 / 055
  • PS5 DualSense: BDM-010 / 020 / 030 / 040 / 050

⚠️ Use a data-capable USB cable. Chrome or Edge only. Page must be HTTPS.

Your browser does not support Web Serial. Use Chrome or Edge. This page must be served over HTTPS or localhost.

Click the button, select your ESP32-C3 COM port, then follow the prompts.

Connection tips

  • Hold BOOT while plugging in / clicking Connect if the board is not detected.
  • Press RST if flashing fails, then try again.
  • Close Arduino IDE, PlatformIO, serial monitors, etc.
