ESP32‑C3 Universal RapidFire Mod

Web Flasher for PS4 & PS5 Controllers
v0.9.12

Flash the Universal RapidFire Mod v0.9.12 firmware onto your ESP32‑C3 installed inside:

  • PS4 DualShock: JDM‑001 / 011 / 020 / 030 / 040 / 050 / 055
  • PS5 DualSense: BDM‑010 / 020 / 030 / 040 / 050
⚠ Use a data‑capable USB cable. Chrome or Edge only. Page must be served over HTTPS (or localhost).

Connection Tips

  • 1 Hold BOOT while plugging in if the board is not detected.
  • 2 Press RST if flashing fails or the port disappears.
  • 3 Close Arduino IDE, PlatformIO, serial monitors, and any other tools using the serial port.
