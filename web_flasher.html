ESP32-C3 Universal PS4 & PS5 RapidFire Mod v0.9.9

Web Flasher (ESP32-C3)

This page flashes the Universal RapidFire Mod v0.9.9 firmware to your ESP32-C3 installed inside:

  • PS4 DualShock: JDM-001 / 011 / 020 / 030 / 040 / 050 / 055
  • PS5 DualSense: BDM-010 / 020 / 030 / 040 / 050

⚠️ Use a USB cable that supports data (not just charging). Chrome / Edge required.

Click Connect, select your ESP32-C3 COM port, then follow the prompts.

Connection tips

  • Hold the controller so the ESP32-C3 is powered via USB.
  • If flashing fails, press the RST button on the ESP32-C3 and try again.
  • Close other serial tools (Arduino IDE, PlatformIO, etc.) before flashing.
