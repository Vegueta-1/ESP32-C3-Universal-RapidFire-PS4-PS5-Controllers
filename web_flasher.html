ESP32‑C3 Universal PS4 & PS5 RapidFire Mod v0.9.11

Web Flasher (ESP32‑C3)

Flash the Universal RapidFire Mod v0.9.11 firmware onto your ESP32‑C3 installed inside:

  • PS4 DualShock: JDM‑001 / 011 / 020 / 030 / 040 / 050 / 055
  • PS5 DualSense: BDM‑010 / 020 / 030 / 040 / 050
⚠ Use a data‑capable USB cable. Chrome or Edge only. Page must be HTTPS.
Your browser does not support Web Serial. Use Chrome or Edge. This page must be served over HTTPS or localhost.

Select your ESP32‑C3 COM port and follow the flashing prompts.

Connection Tips

  • Hold BOOT while plugging in if not detected.
  • Press RST if flashing fails.
  • Close Arduino IDE, PlatformIO, serial monitors, etc.
